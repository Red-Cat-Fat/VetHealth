# Давление: усреднение замеров (BPAverage)

Программа для Windows: забирает замеры с тонометра CONTEC08A, из файлов BPMeter или из PDF-отчётов,
копит их в одном архиве, делит на серии, считает средние без сбоев и выбросов и рисует график.

## Установка
Ничего ставить не нужно. Скопируйте `BPAverage.exe` в любую папку, например `C:\BPMeter\Усреднение`,
и запустите. Это один файл примерно на 90 МБ: .NET и все библиотеки уже внутри.
Windows 10 или 11, 64 бит.

При первом запуске Windows SmartScreen может предупредить о «неизвестном издателе»:
нажмите «Подробнее» → «Выполнить в любом случае». Файл не подписан сертификатом.

## Как пользоваться
- **Скачать с аппарата.** Закройте BPMeter, подключите аппарат по USB, нажмите кнопку.
- **Импорт из BPMeter.** Берёт все `C:\BPMeter\data\*.awp`. С зажатым Shift можно выбрать файлы вручную.
  При первом запуске это делается само, если архив пуст.
- **Импорт PDF…** Отчёты BPMeter в PDF, как раньше.

Новые замеры дописываются в `замеры_архив.csv` рядом с программой, повторы отсеиваются.
Если в папку программы писать нельзя, архив лежит в `%LOCALAPPDATA%\BPAverage`.
Формат архива тот же, что у прежнего скрипта на Python.

## Что на экране
- **Слева** список серий, сверху самые новые: дата, время, среднее, сколько замеров учтено, пометки.
- **График**: по оси X время, по оси Y давление.
  - ромбы с линией: среднее каждой серии (SYS красным, DIA синим);
  - бледные точки: замеры, которые вошли в среднее;
  - оранжевые крестики: замеры, которые не вошли (сбой аппарата или выброс);
  - чёрный кружок: ненадёжная серия, лучше перемерить;
  - пунктир: 140 и 90.
  Колёсико мыши меняет масштаб, перетаскивание двигает график. Если навести мышь на серию,
  появится подсказка со всеми её замерами. Щелчок выделяет серию.
- **Внизу** замеры выбранной серии. Не учтённые перечёркнуты, рядом указана причина.
- Переключатель «График»: «Средние и замеры», «Только средние», «Только замеры» (с пульсом).
- «Новая серия после паузы, мин»: по умолчанию 10.

## Выгрузка
- **Сохранить Excel…** Листы «Серии», «По дням», «Все замеры», «График» (картинка).
- **Сохранить график…** Картинка PNG.
- **Для Google Таблиц…** Сохраняет Excel и PNG в выбранную папку и открывает Google Диск.
  Перетащите .xlsx на Диск и откройте его «в Google Таблицах». PNG можно вставить в Google Документ.
  Прямой выгрузки в Google нет: для неё нужен свой проект в Google Cloud и вход через Google-аккаунт.
  Это можно добавить позже.

## Как считается
- **Серия**: замеры подряд с паузой не больше 10 минут.
- **Сбой аппарата**: SYS < 85, DIA < 50, или разница SYS−DIA ≤ 20 либо ≥ 80. Такие замеры не учитываются.
- **Выброс**: в серии от 3 годных замеров значение отличается от медианы серии больше чем на 20 (SYS)
  или 15 (DIA). Если «выбросов» больше половины, ничего не отбрасывается.
- **Ненадёжная серия**: годных замеров меньше половины или их SYS разбегается больше чем на 25.

## Протокол аппарата
CONTEC08A, USB HID, VID 0483, PID 5750. Описание в `BpCore/Device.cs`.

## Исходники и сборка
- `BpCore`: чтение (аппарат, .awp, PDF), анализ, архив, Excel. Обычная библиотека .NET 8.
- `BpApp`: окно WinForms и график (ScottPlot).
- `BpTests`: проверка на реальных данных: `dotnet run --project BpTests -- <папка с образцами>`.
  Образцы (файлы .awp, PDF-отчёты, запись обмена с аппаратом) — личные данные, поэтому в репозиторий не входят;
  список нужных файлов в начале `BpTests/Program.cs`.
- `BpChartPreview`: рисует график в PNG без окна, чтобы проверить его внешний вид.

Сборка exe (Windows или Linux, .NET 8 SDK), результат — один файл `publish/BPAverage.exe`:

    dotnet publish BpApp -c Release -o publish

Прежние скрипты на Python лежат в `legacy/python`. Они тоже работают, но больше не нужны.
